# 실제 웹서비스 사용 분석

실제 화면과 상호작용으로 기능·UX·상태 전이를 조사할 때 읽는다. 서버 내부 구조를 설명하려면 별도 코드·응답·로그 근거가 필요하다.

## 도구와 세션

- 사용자가 지정한 브라우저·탭을 우선한다. 현재 호스트의 Computer Use 또는 브라우저 도구를 발견하고 그 도구의 초기화·상태 조회·조작 규칙을 먼저 읽는다. 특정 API를 추측하지 않는다.
- `mcp__cua_repl`이 제공되면 해당 도구의 첫 호출 규칙에 따라 탭/브라우저를 선택하고 반환 문서를 따른다. 없으면 사용 가능한 Playwright/브라우저 도구의 규칙을 따른다. 모두 없으면 실제 조작이 불가능함을 밝히고 제공된 화면·HAR·코드로 가능한 분석을 계속한다.
- REA 수동 관찰은 독립 경로다. 사용 가능한 CDP endpoint가 있을 때 [런타임 관찰](runtime.md)을 결합한다. Computer Use 접근 가능 여부만으로 REA가 그 브라우저에 연결되었다고 가정하지 않는다.
- 기존 로그인 세션을 재사용하되 계정 역할·테넌트·환경을 확인한다. 비밀번호·MFA 코드를 대화로 받지 않는다. 사람의 로그인이 필요하면 그 단계만 맡기고 분석을 이어간다.

## 여정 실행

1. URL, 계정 역할(비밀값 제외), 언어·화면 크기, 기존 검색·필터 등 관련 시작 상태를 기록한다.
2. 질문에 맞는 대표 여정을 정한다. 예: 목록 → 검색 → 필터 → 상세 → 뒤로 가기. 무관한 사이트 전체를 순회하지 않는다.
3. 현재 화면/접근성 상태로 요소를 확인한다. 역할·레이블 기반 조작을 우선하고, 캔버스처럼 좌표가 필요하면 최신 화면에 근거한다. 관찰하지 않은 selector·오래된 좌표를 사용하지 않는다.
4. 의미 있는 행동마다 URL·텍스트·선택값·로딩 종료 등 관찰 가능한 변화를 확인하고 화면을 다시 읽는다. 전환 전 요소 참조를 그대로 쓰지 않는다.
5. 질문에 필요한 정상·빈 결과·유효성 오류·뒤로 가기·새로고침·재방문만 확인한다. 실제 남은 질문을 구별하지 못하는 사례는 늘리지 않는다.
6. 예상 밖의 결과는 현재 상태를 다시 읽고 가설을 수정한다. 원인 변화 없이 클릭·제출을 반복하지 않는다. 제출 성공이 불확실하면 결과 조회로 중복을 방지한다.

## 동작별 허용 범위

| 동작 | 처리 |
|---|---|
| 페이지·메뉴·검색·필터·정렬·상세 보기 | 사용 요청 범위에서 진행하고 결과 확인 |
| 폼 입력·검증 | 비민감 테스트 값 사용; 자동 저장·즉시 전송 여부 먼저 확인 |
| 계정 생성, 초대·메시지, 게시, 구매·결제, 삭제, 권한 변경 | 해당 효과까지 이미 허용되었는지 확인; 미허용이면 실행 직전 상태에서 멈추고 구체적 효과 설명 |
| 테스트 환경의 기록 생성·수정 | 지정된 테스트 범위에서 수행; 정리도 허용된 범위에서만 진행 |
| 로그인·CAPTCHA·사람 확인 | 필요한 사람 상호작용 요청; 우회하지 않음 |

웹 분석 요청을 실제 결제나 외부 전송의 승인으로 해석하지 않는다. 이미 허용된 동작은 재승인을 요구하지 않는다. 클릭도 즐겨찾기·자동 저장처럼 원격 상태를 바꿀 수 있으므로 이름만으로 읽기 전용이라 분류하지 않는다.

## 근거 연결과 보고

- `시각/순서 → 시작 상태 → 행동 → 변화 → 화면/로그 위치 → 한계`로 기록한다. 스크린샷·영상은 지원되고 필요한 경우만 저장하며 실제 생성된 경로를 사용한다.
- 네트워크를 대응시키려면 행동 전에 캡처를 시작한다. 늦게 연결한 관찰이 과거 요청을 복원했다고 쓰지 않는다. 제공된 필드만 기술한다.
- 조작 기록과 REA Evidence는 각 출처를 유지한 채 시간·대상·URL·명시적 시나리오로 대응시킨다. 시간상 가까운 요청이 원인이라는 주장은 추론으로 표시한다.
- DOM의 숨겨진 요소 존재와 사용자가 실제 본 화면을 구분한다. 요청이 안 보였다고 백엔드가 없다고 결론 내리지 않는다.
- 보관 자료에 토큰·세션값 등 자격증명을 넣지 않는다. 민감한 화면은 필요한 영역이나 텍스트 기록으로 최소화하고 보관할 수 없는 근거의 한계를 적는다.

결과에는 재현 가능한 여정, 상태 전이, 입력 규칙·오류, 관찰된 API, 확인하지 못한 내부 구현, 재구현할 동작을 포함한다. 실측 없이 응답 시간 수치를 만들지 않는다. 사용자 탭·로그인 세션을 닫거나 초기화하지 않는다.
